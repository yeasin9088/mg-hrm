First-time Setup

Paste your Supabase Project URL and anon key below.
Best practice: do this once on the admin device, then save these into config.js in your GitHub repo — every future device will connect automatically.

  1. Open Supabase → left menu → Project Settings (⚙ icon)
  2. Click the API tab
  3. Copy Project URL into field 1 (starts with https://)
  4. Copy the long anon / public key into field 2
Only anon public key — never service_role
